# Spec Desain — CMS Dokumen: SOP (dikelola) + SK LAB (menu baru)

Tanggal: 2026-09-30 (WIB)
Versi target: **v5.5.0**
Klasifikasi: **architectural** (subsistem baru: CMS dokumen + penyimpanan file PDF)
Status: **disetujui PM 30 Sep 2026**

## Latar belakang

Halaman `/dokumen/sop-perikanan` dan `/dokumen/sop-tangkap` sekarang menampilkan
daftar PDF yang **hardcode** di komponen dan disimpan sebagai file statis di
`public/dokumen/`. Setiap perubahan daftar dokumen memerlukan deploy ulang.
Belum ada halaman SK LAB.

Permintaan PM:

1. SOP (Perikanan & Perikanan Tangkap) diubah agar bisa **diunggah/dikelola
   system admin**.
2. Tambah menu baru di Dokumen: **SK LAB**, juga dikelola system admin.

Penyimpanan file: **Cloudinary** (dikonfirmasi PM) — mengikuti pola yang sudah
terpasang untuk materi dosen (`resource_type: raw`), bukan Cloudflare R2.

## Keputusan yang sudah disetujui

| Topik | Keputusan |
|---|---|
| Penyimpanan | Cloudinary, folder `dolphin_dokumen`, resource type `raw` |
| Struktur SK LAB | Satu daftar (tanpa pengelompokan per lab) |

Satu tabel melayani tiga kategori. Halaman publik memfilter per kategori;
panel admin memakai chip kategori untuk berpindah.

## Skema database

```sql
create table public.dokumen (
  id          bigint generated by default as identity primary key,
  kategori    text not null
                check (kategori in ('sop-perikanan','sop-tangkap','sk-lab')),
  judul       text not null check (char_length(judul) between 1 and 150),
  nomor       text check (nomor is null or char_length(nomor) <= 50),
  tanggal     date,
  deskripsi   text check (deskripsi is null or char_length(deskripsi) <= 300),
  file_url    text not null,
  file_type   text not null default 'pdf',
  is_visible  boolean not null default true,
  sort_order  integer not null default 0,
  uploaded_by text,
  created_at  timestamptz not null default now()
);
```

Indeks: `(kategori, is_visible, sort_order)` untuk query halaman publik.

### RLS

- `dokumen_public_read`: SELECT untuk `anon` + `authenticated` bila
  `is_visible = true`.
- `dokumen_admin_read`: SELECT untuk system admin (semua baris).
- `dokumen_admin_write`: INSERT/UPDATE/DELETE bila `is_system_admin()`.

Mengikuti pola v5.3.0: `is_system_admin()` adalah SECURITY DEFINER dengan
`search_path = ''`, menghindari hardcode email di policy.

### Seed

13 baris dari daftar hardcode saat ini, memakai **path lokal yang sudah ada**
(`/dokumen/....pdf`) sehingga halaman publik identik pada hari pertama. Nama
file dipertahankan persis, termasuk perbedaan huruf besar/kecil.

## Penyimpanan file

- Preset unsigned baru: `dolphin_dokumen` (folder `dolphin_dokumen`,
  resource type `raw`) — dibuat PM di dashboard Cloudinary.
- Env baru: `NEXT_PUBLIC_CLOUDINARY_UPLOAD_PRESET_DOKUMEN`.
- Endpoint unggah: `https://api.cloudinary.com/v1_1/<cloud>/raw/upload`.
- Validasi: MIME/ekstensi PDF, maks 10 MB, di klien dan saat unggah.
- Penghapusan memakai `/api/delete-cloudinary` yang sudah ada (wajib login,
  guard host akun, `resource_type: raw`).

## Penanganan error

| Kasus | Perilaku |
|---|---|
| DB tidak terbaca / kosong | Fallback daftar statis (halaman tidak pernah kosong) |
| File > 10 MB atau bukan PDF | Ditolak sebelum unggah, pesan jelas |
| Unggah Cloudinary gagal | Pesan error dari Cloudinary ditampilkan, tidak insert baris |
| Hapus baris gagal, file Cloudinary gagal | Baris DB tetap dihapus; kegagalan file dilaporkan |
| File seed (URL lokal) dihapus | Baris dihapus; file statis di server dibiarkan |

## Rollback

- Kode: `git revert` commit rilis, build & deploy ulang.
- DB: `drop table public.dokumen;` (data seed bisa dibuat ulang dari migrasi).
- File statis lama di `public/dokumen/` tidak dihapus, jadi rollback halaman
  publik tetap aman.
