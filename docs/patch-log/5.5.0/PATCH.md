## Perubahan Database (migrasi `v550_dokumen_cms`)

```sql
create table public.dokumen (
  id bigint generated by default as identity primary key,
  kategori text not null check (kategori in ('sop-perikanan','sop-tangkap','sk-lab')),
  judul text not null check (char_length(judul) between 1 and 150),
  nomor text check (nomor is null or char_length(nomor) <= 50),
  tanggal date,
  deskripsi text check (deskripsi is null or char_length(deskripsi) <= 300),
  file_url text not null,
  file_type text not null default 'pdf',
  is_visible boolean not null default true,
  sort_order integer not null default 0,
  uploaded_by text,
  created_at timestamptz not null default now()
);
create index dokumen_kategori_visible_sort_idx
  on public.dokumen (kategori, is_visible, sort_order);
alter table public.dokumen enable row level security;
```

Policy:

| Policy | Role | Aturan |
|---|---|---|
| `dokumen_public_read` | `anon`, `authenticated` | SELECT bila `is_visible = true` |
| `dokumen_admin_read` | `authenticated` | SELECT semua baris via `public.is_system_admin()` |
| `dokumen_admin_write` | `authenticated` | ALL (insert/update/delete) via `public.is_system_admin()` |

Hak tabel: `anon` hanya `SELECT` (INSERT/UPDATE/DELETE/TRUNCATE/REFERENCES/TRIGGER di-revoke — pertahanan berlapis bila policy keliru).

Seed: 13 baris (4 `sop-perikanan`, 9 `sop-tangkap`), `is_visible = true`, `sort_order` 1..n, `uploaded_by = 'seed'`, `file_url` menunjuk PDF lokal di `public/dokumen/`.

## Uji PM

1. Beranda → navbar **Dokumen**: pastikan ada entri **SK Lab** (desktop & mobile).
2. `/dokumen/sop-perikanan` dan `/dokumen/sop-tangkap` tetap menampilkan 4 + 9 dokumen lama.
3. `/dokumen/sk-lab` menampilkan pesan “Belum ada SK Lab” (belum ada data).
4. Login system admin → `/admin/system` → tab **Dokumen**:
   - Chip kategori berpindah daftar dengan benar.
   - **Tambah dokumen**: pilih PDF > 10 MB → ditolak; bukan PDF → ditolak; PDF valid + judul → tersimpan dan muncul di halaman publik.
   - **Ubah**: ganti judul/nomor/tanggal/deskripsi tanpa mengganti file → tersimpan.
   - **Tampil/Sembunyi**: sembunyikan → hilang dari halaman publik (setelah ≤5 menit ISR); tampilkan → muncul lagi.
   - **Geser urutan** atas/bawah → urutan halaman publik berubah.
   - **Hapus**: muncul konfirmasi Swal; setelah hapus, baris hilang dan file Cloudinary ikut terhapus.
5. Pastikan semua aksi hapus memakai dialog Swal (tidak ada `confirm()` browser).

## Rollback

- Kode: `git revert <commit>` lalu build + deploy ulang.
- DB: `drop table public.dokumen;` (halaman publik otomatis kembali memakai fallback statis). Seed tidak menyentuh tabel lain.
- Cloudinary: file PDF yang sudah diunggah dapat dihapus manual dari dashboard; seed memakai file lokal sehingga tidak terpengaruh.
